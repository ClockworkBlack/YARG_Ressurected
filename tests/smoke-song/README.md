# Smoke test song

A tiny song made for the automated play tests of the Windows, Mac and Linux builds
(`overlay/Assets/Script/Testing/SmokeTest.cs`). The chart (`notes.chart`, 81 notes on Expert guitar,
one per beat at 120 BPM, every eighth one a two-fret chord) and the audio (`song.ogg`, one tone per note, synthesized with ffmpeg) were
generated for this repo and are free to use for anything (CC0).
