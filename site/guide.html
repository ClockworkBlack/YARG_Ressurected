Gamepads

The game is set up for a PS5 DualSense (a PS4 controller works the same way) and uses the usual PlayStation buttons. Xbox, Switch and generic Android pads work too: pick yours in Settings → General → Controller Layout.

While a gamepad is connected, the bar at the bottom of the screen names the button for each action (for example "Back Circle"). To turn this off, use Settings → General → Show Controller Button Names.

A gamepad in a profile uses that profile's menu buttons, which are set from the Controller Layout when you add the gamepad. After changing the layout, remove the gamepad from its profile and add it again, or change the buttons in the profile's binding menu.

Phone remote: friends' phones as guitars and mics

Other phones on the same Wi-Fi (or on your hotspot) can join from their browser, with nothing to install.

  1. No shared Wi-Fi?On the host, tap the PHONES bar on the main menu, then Start game network. YARG starts a private Wi-Fi network (no internet) and shows a QR code to join it, plus a second one to open the page. Android asks for the "Nearby devices" permission the first time (Location on Android 12 and older).
  2. Find the addressOn the host, the main menu shows a PHONES bar with the address. Tap it for QR codes.
  3. Open it on the guest's phoneThe browser warns that the connection isn't private, because the certificate is self-signed. Tap Advanced → Proceed. On iPhone, use Safari: Show Details → visit this website.
  4. JoinType a name, pick Guitar, Bass or Vocals and a difficulty, then tap Join. Turn the phone sideways. The host adds a player for that phone automatically between songs. A phone that joins mid-song is added when the song ends. Pick Controller only if you want to set the phone up yourself in Profiles.
    • Play tab: tap the colored Lanes (each tap strums, and chords work), or switch to Frets for frets, a strum pad and whammy.
    • Menu tab: D-pad, OK, Back and Start for moving around YARG's menus.
    • Mic tab: Start mic streams the phone's mic to the host for vocals.
  5. Set it up by hand (optional)On the host: Profiles → pick or make a profile → Add Device → "<name> (phone)" for the controller, or "Phone mic: <name>" for a vocals profile. The phone's profile reconnects by itself next time. The host's own mic shows up as "This phone's mic".

How timing is kept tight

  • Each phone syncs its clock with the host and stamps every press with the moment the screen was touched.
  • The host plays each press a fixed few milliseconds after that moment, a bit more than the connection's usual delay (measured between songs). This keeps Wi-Fi jitter out of the game. The host also shifts that player's input calibration by the same amount, so each press is judged at the moment of the touch.
  • While phones are connected, Android's Wi-Fi power saving is turned off for the app.
  • The game runs at the screen's refresh rate (120 Hz on a Z Fold 7) when the FPS cap is left at 60.
  • The http:// address works too, but only for the controller. Browsers only allow the mic on https://.
  • Each build makes a new self-signed certificate, so guests see the warning again after an update.
  • Anyone on the same Wi-Fi can open the page, so only use it on networks you trust.
  • Wi-Fi adds a little delay. If timing feels off, run YARG's calibration with a phone.

Menu music: a startup song and a playlist

The menus play songs from your library in the background. You choose what plays:

  • A song on startup. In the music library, highlight a song, open More Options (orange / LB) and choose Play On Startup. It plays first every time the game starts, then the menu music carries on as below. To turn it off, choose Don't Play On Startup on the same song, or set Settings → Sound → Startup Song to None.
  • Which songs play after it. Settings → Sound → Menu Music: Whole library, Favorites, or any of your playlists. Or, in the music library's Playlists view, highlight a playlist (or Favorites), open More Options and choose Use As Menu Music (Stop Using As Menu Music goes back to the whole library). The music switches right away.
  • Order. Settings → Sound → Shuffle Menu Music: on plays songs in random order, off plays the playlist in its own order and loops it.
  • Volume is still Settings → Sound → Music Player Volume. Set it to 0 to turn menu music off.

If the playlist is empty, deleted, or none of its songs are in the library, the whole library plays instead.

Song Setup: speed, key, a section, freestyle

After picking a song, the instrument / difficulty screen shows a SONG SETUP bar at the bottom. Tap it to open a screen where you can change these while listening to the song:

  • Speed, from 50% to 200%. This is the same setting as the game's own song speed box.
  • Key, up to 12 semitones down or up, without changing the speed. The generated guitar and freestyle notes move with it.
  • Section. A bar shows the whole song. Drag its two yellow ends to choose where to start and stop, tap anywhere on the bar to hear the song from there, or use Start here / End here while it plays. The preview loops the chosen part at the chosen speed and key. If you start a song with a section chosen, it plays in practice mode on that part, on repeat.
  • Freestyle guitar. This stays on until you turn it off or close the game. Every strum plays a real guitar note at once, chart or no chart, in the song's own scale and tuning:
    • the five frets are the five notes of the song's pentatonic scale, with green lowest; a strum with no fret plays the note just below green;
    • strum down for the low octave, strum up for the octave above;
    • two frets make a power chord, three or more a fuller chord;
    • change frets while a note rings to hammer on or pull off, and let go of all frets to stop it;
    • the whammy bar bends the note down.
    With freestyle on, your instrument gets no generated track (you are the guitar), and wrong strums don't clunk. The chart still scrolls and scores as usual, so you can follow it or ignore it. Works for five-fret guitar, bass and rhythm.

These settings belong to the song you opened the screen for. Picking a different song resets to normal speed, the original key and the whole song.

Guitar sound on your notes

Guitar Hero songs come with the guitar on its own audio track: it plays while you hit notes and cuts out when you miss. Songs you add yourself (and everything from the Converter) are a single recording, so there is nothing to cut. With Settings → Sound → Guitar Sound On Notes on (the default), the game makes that track while the song loads:

  1. It listens to the song.It works out the recording's tuning (many songs aren't at exactly A = 440 Hz), its scale, and which note the music is on at each moment, separately for the guitar and bass range.
  2. It gives every note of your chart a pitch.That's the note the song is on, in an octave chosen so the line goes up when the frets go up and repeats when they repeat. Two- and three-fret notes become power chords on the harmony's root note.
  3. It plays the chart on a modelled electric guitar(or bass, for a bass player): plucked strings through an amplifier and speaker cabinet, with hammer-ons softer than picked notes, vibrato on long notes and strummed chords. There are three sounds: Clean, Rock and Heavy.

The result is added to the song as its guitar (or bass) track, so the game treats it like the real thing. It sounds exactly on the notes whatever your audio delay (including Bluetooth), drops out when you miss and comes back on the next hit, bends with the whammy bar on sustains, gets the Star Power reverb, follows the Guitar / Bass volume sliders, and works in practice mode at any speed. A wrong strum still makes the game's own "clunk".

  • Only for five-fret guitar, bass and rhythm, and only when the song has no separate audio for that instrument. Songs with a real guitar track are left alone.
  • With several guitarists on one instrument, you hear the hardest difficulty being played.
  • "Mute On Miss" must not be Off for the sound to drop out on misses (it's on by default).
  • Loading takes a few seconds longer. Songs over 20 minutes are skipped.
  • Every build's release includes guitar-sound-demo.wav: the three guitar sounds and the bass, recorded by the automated tests.

Error logs on the phone

The game keeps a copy of its log next to your songs, in Internal storage/YARG/logs, so you can open or send it from any file manager:

  • yarg-errors.txt: only the errors, from every run, with the build and phone they happened on. This is the file to send when something goes wrong.
  • yarg-log-<date>_<time>.txt: everything the game logged in one run. The newest 10 are kept.

It records errors the game caught, exceptions nothing caught (with where they happened), and low-memory warnings. If a song fails to start, a dialog says why and the game goes back to the menu, instead of stopping on an empty screen. Nothing is uploaded: the files stay on the phone. A crash inside a native library (the app closing with no message) isn't recorded.

To report a problem, open an issue on GitHub and attach yarg-errors.txt.

Build it yourself

Every build comes from GitHub Actions: it downloads YARG-DROID at a pinned commit, applies this repo's patches and overlay, builds the arm64 native libraries with the Android NDK, then builds the APK with Unity and publishes it as a GitHub Release. To build your own copy, fork the repo and follow the one-time setup in the README (a free Unity personal license and three repository secrets), then run Actions → Build Android APK → Run workflow.
